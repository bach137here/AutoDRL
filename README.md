# AutoDRL
Tool giúp bạn auto fill các Form kiếm ĐRL.

## Hiện tại chỉ hỗ trợ Microsoft Form.

## Cách dùng:

1) Vào Form bạn cần auto-fill, dán đoạn code vào Console.
2) Ấn "Copy Prompt gửi AI" sau đó dán toàn bộ vào mô hình AI của bạn.
3) Dán kết quả dạng JSON AI trả về và tool sẽ tự động auto-fill.

## TIPS: Để tăng độ chính xác cho đáp án bạn có thể thêm cho AI nhiều context về chủ đề bạn đang làm.
